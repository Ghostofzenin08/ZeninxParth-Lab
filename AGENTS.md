# Workspace Rules

## Git & Repository Commit Rules
Whenever asked about creating a repository or committing changes:
1. Commit strictly **1 file at a time** (never bulk-commit multiple files in a single commit).
2. Keep commit messages **short and concise** (not too lengthy).
3. **Never use conventional commit words or prefixes** such as `feat`, `chore`, `chores`, `fix`, `fixes`, `docs`, `refactor`, `style`, `test`, `ci`, or `perf`.
