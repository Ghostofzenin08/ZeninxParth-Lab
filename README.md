## 🪐 3D Graphics, Simulations & Interactive Engines

### 1. Three.js WebGL Celestial Galaxy Simulation
* **Real-time Particle Dynamics**: Thousands of individual stellar particles calculated along logarithmic spiral arms with central galactic bulge accretion.
* **Interactive Controls**: Dynamic mouse camera tilt, drag-to-rotate inertia damping, spectral arm color shifts, and Turbo Warp acceleration.
* **GPU Preservation**: Integrated with `IntersectionObserver` to automatically suspend frame loops when scrolled out of viewport.

### 2. 3D Keplerian Orbit Mechanics Simulator
* **Keplerian Trajectory Propagation**: Solves orbital dynamics and the vis-viva velocity formula in real time:
  $$\nu^2 = \mu \left( \frac{2}{r} - \frac{1}{a} \right)$$
* **3 Interactive Presets**:
  * ☀️ **Solar System**: Multibody planetary distances with Earth-analog orbital velocities.
  * ☄️ **Halley-Class Comet**: High-eccentricity ($e = 0.88$) trajectory with visible perihelion speed acceleration.
  * 🌌 **Binary Star Resonance**: Dual central stars orbiting a shared barycenter with circumbinary exoplanets.
* **Live Telemetry Readout**: Semi-major axis ($a$), eccentricity ($e$), orbital velocity ($v$), and mechanical energy ($E$).

### 3. Interactive Astraea Station Simulator (*ORBITAL*)
* **13 Connected Compartments**: Docking Bay, Maintenance Corridor, Fusion Core, Airlock Chamber, Life Support, Specimen Vault, Bridge, and more.
* **Dual Telemetry Switching**:
  * **Feel Mode**: Atmospheric soundscapes, heartbeat degradation, dynamic lighting occlusion, biometric alert beacons.
  * **Logical Mode**: Detailed engineering data bus tracking coolant pressure, megawatt draw, and reactor critical temperature curves.
* **Tactical Airlock Purge**: Enforces stalking predator detection inside the Airlock Chamber before engaging toxic chemical or vacuum decontamination.
* **Synthesized Web Audio Engine**: Procedural Geiger counter clicks, power-grid hums, hydraulic valve seals, trauma heartbeats, and alert sirens.

### 4. Interactive In-Browser Sandboxes
* **Glassmorphic Auth Sandbox**: Live 3D card flipping, password entropy calculation, and reactive validation.
* **Snipy Developer HUD**: Quick-capture code modal simulator supporting multi-language syntax tagging (Python, JS, GDScript, GLSL) and one-click markdown clipboard export.
* **Echo of Dread 30s Time Loop Simulator**: Demonstrates multi-echo causal choreographies and timeline state rewind.

## ⚡ Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/Ghostofzenin08/ZeninxParth-Lab.git
cd ZeninxParth-Lab

# 2. Install dependencies
npm install

# 3. Start local Vite development server
npm run dev

# 4. Compile production bundle
npm run build

# 5. Preview production build locally
npm run preview
```

## 🌐 Continuous Deployment

This repository is configured with automated continuous delivery:
* Every push to `main` executes `.github/workflows/deploy.yml` which builds the Vite production bundle and pushes the output to the `gh-pages` branch.
* Manual deployments can be performed at any time via:
  ```bash
  npm run deploy
  ```
* Live at: **[https://ghostofzenin08.github.io/ZeninxParth-Lab/](https://ghostofzenin08.github.io/ZeninxParth-Lab/)**
