# ZeninXParth Upgraded Dual-Theme Portfolio

A modern portfolio hub showcasing indie games, machine learning APIs, and frontend engineering built with **React**, **Tailwind CSS**, **Lenis**, and **Framer Motion**.

## ?? Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```

## ?? Key Features
- **Dual-Theme System**: Obsidian Dark mode with `#ff0207` red cyber accents & crisp Light mode with instantaneous toggle and localStorage sync.
- **Lenis Smooth Scroll**: Kinetic inertial scrolling for a native app feel.
- **Framer Motion**: Graceful section reveals and animated state transitions.
- **Case Study Hub**: In-depth architecture write-ups for:
  - ZeninXParth Platform (Meteor Dodge & BlockRush)
  - Resumatch API
  - Enhanced Pong Game
  - Game Development in Python
- **Dynamic Interactive Canvas**: Low-overhead particle vector background.
- **About & Vision**: Showcases Computer Science foundations alongside MPSC & Talathi competitive exam discipline.
